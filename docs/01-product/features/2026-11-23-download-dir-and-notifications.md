# 下载目录选择、图片目录扫描与系统通知

## 1. 背景与目标

- 解决痛点：
  1. 追更发现新章节、图库/Pixiv 保存图片缺少 Windows 系统通知提醒；
  2. 用户在关闭「默认目录直存」后手选目录保存图片，「本机内容 → 图片」不扫描手选目录，导致仍显示 `图片 (0)`；
  3. 漫画离线下载目录固定在数据根下，设置页与「选择下载章节」弹窗均无法修改下载路径。
- 核心目标：补齐追更与图片下载系统通知；记录手选存图目录并在本地图片库合并扫描；支持设置与弹窗切换漫画下载目录。
- 非目标（Non-Goals）：不做旧漫画目录向新目录的自动搬迁拷贝（避免阻塞 UI 与大磁盘 I/O，用户随时可恢复内置目录查看旧漫画）。

## 2. 用户操作流

1. 入口：
   - 漫画下载目录：设置页「下载目录」卡片 / 漫画详情页「选择下载章节」弹窗底部「更改目录」。
   - 图片保存：图库卡片/看图器/Pixiv 作品保存图片。
   - 追更通知：追更中心手动检查或启动自动检查。
2. 过程：点击「更改目录」弹出系统原生文件夹选择框（`DesktopDirChooser`）；存图落在手选目录时自动记入 `extraImageDirs`；存图成功或追更发现新章节时触发托盘系统通知。
3. 结果：漫画新下载落入所选目录；「本机内容 → 图片」即时刷新并展示所有已存图片；系统通知中心收到提示。

## 3. 范围

- 涉及屏与路由：`DesktopSettingsHub`、`DesktopComicDetailScreen`、`DesktopDownloadsPipelineScreen`、`DesktopFollowUpdateChecker`。
- 涉及表与列：无数据库表变更，仅在 `DesktopGalleryPreferences` 新增 `pref_comic_download_dir`、`pref_extra_image_dirs` 两个桌面自持偏好键。
- 涉及启动参数或构建项：无。

## 4. 边界与异常

- 空态：目录为空或不存在时自动跳过不报错。
- 失败：目录选择框取消时不修改当前配置；不可写目录仍按既有失败提示处理。

## 5. 验收

- 判据：`:desktop:compileKotlin`、`:desktop:checkDuplicateImports`、`:desktop:test` 全绿；新增/更新对应单元测试覆盖多目录扫描。
- 端到端验证：安装版实测追更/存图弹窗通知、手选目录存图后在「本机内容 → 图片」可见、更改漫画下载目录后新下载落入目标文件夹。
