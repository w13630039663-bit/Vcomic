# VComic v1.0.2 更新说明

## 新特性与体验升级
- **全窗通透材质重塑与 Acrylic / Mica 切换**：升级侧栏为悬浮感极简 Air Glass / Bento 风格并配独立发丝分界线；原「首页皮肤」升级为「模糊效果（Acrylic / Mica）」，支持实时天气 Bento 卡片与圆形扩散主题切换动效，并修复浅色透明模式下整窗偏暗发灰问题。
- **桌面端顶层像素互动伙伴（Pixel Buddy）**：支持 1~3 只 2px 极简像素小家伙在侧栏、顶栏、搜索框与首页/图库/漫画搜索卡片上巡逻、贴贴与叠罗汉；具备搜索框拼字、跨列踩台阶 + 多米诺光流点亮、全窗替换 16×16 大号像素逗猫棒指针追逐，以及下载搬砖、深夜小睡帽、收藏/取消收藏与回窗迎接联动（后台失焦零耗电休眠，老侧栏小鱼桌宠默认关闭）。
- **全源搜索书签、EH 种子下载与网络收藏增强**：
  - 漫画搜索新增可置顶「快速搜索书签栏」一键复用搜索条件；
  - 新增通用 `.torrent` 种子扩展并在 `ehentai.js` 率先支持，详情页可直接查看/下载种子；
  - 网络收藏新增收藏备注（`favnote`）、夹内搜索与多选批量移动/批量取消收藏。
- **源仓库切换、测速监控与画廊分页**：支持官方源与社区稳定源仓库切换（带 jsDelivr 回退）与独立线路延迟测速监控页；画廊搜索新增「确定性分页切换 + 页码跳转条」并升级分享卡片高清渲染。

## 关键问题修复
- 修复 Hitomi 缩略图子域硬编码失效与 `gold-usergeneratedcontent.net` 代理识别遗漏导致的图片加载失败。
- 修复 Pixiv 榜单缺少作者头像以及作品详情页多页异形图出现大片灰框问题（图片解码后自适应真实像素比例）。
- 修复像素互动伙伴点击偶发失灵、全屏拦点击、搜空/失败落点半空卡跳、顶栏最近搜索跨页动画错位，以及高频重排引发的高 CPU 占用问题；补全设置弹窗 `<= 15` 字适用范围说明与逗猫棒开关控件。
- 拆解并优化阅读器底部 HUD 与壳层沉浸态挂手。

## 下载说明
- **Windows (x64)**：
  - `VComic-1.0.2-setup.exe`：单文件自解压图形化安装程序（支持旧版覆盖升级，免管理员权限）。
  - `VComic-1.0.2-portable-win-x64.zip`：解压即用的绿色便携包。
- **Linux (x64)**：
  - `VComic-1.0.2-linux-x64.AppImage`：单文件可执行镜像（赋予可执行权限即可运行）。
  - `VComic-1.0.2-linux-x64.tar.gz`：绿色便携压缩包。
