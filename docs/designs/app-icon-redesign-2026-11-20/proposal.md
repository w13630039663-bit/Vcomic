## 设计边界

- **保留**：V 字母识别度（venera 首字母，名字保留上游前缀后的身份锚点）；蓝色系基调（对齐 VDDS accent `#0A63F6` / `#0A84FF` 派生）。
- **舍弃**：上游的月亮、星、蝙蝠翼、粉丝带四件装饰。
- **新意象池**：鲸尾 / 翻页 / 开卷 / 极简错色（配桌面图库+漫画阅读定位）。

## 统一要求

- 底板：squircle 圆角方（半径约 22.6%），accent 蓝系对角渐变；深浅任务栏双态均需可辨。
- 每案必须过 16px 生死线：V 清晰为主判据，配角元素允许退化但不得糊成污点。
- 首选案落码时输出多尺寸 ICO（16/24/32/48/64/128/256），替换三处接入点并评估是否连带改资产文件名。

### 派系重定向（2026-11-20）

- 主人贴三例截图（DeepSeek 白鲸 / Qoder / magpie 喜鹊），明确转向**剪影派**：纯白或纯色底板 + 单色动物剪影，弃渐变、弃 V 主角位。
- 新稿 `app-icon-silhouette-2026-11-20.html`：白鲸四姿态（跃鲸 / 平游 / 蜷月 / 沉鲸吐泡）× 双底板（白底黑鲸主推、深蓝白鲸对照），剪影走 `currentColor`、眼点走 `--eye`，双底板共用同一鲸形。
- V 血统降级为彩蛋：跃鲸/沉鲸叉尾天然是倒 V。
- 派系固有取舍：白板在浅色任务栏融边，稿内白板加 1.5px 极淡描边近似系统真实观感。

### 网格版轮（2026-11-20）

- 主人自拟两稿：①两卡斜叠稿（空框 + 实卡，负空间即 V）——评价为高，V 拆成两笔的构图法优于此前所有稿，可作为构图资产归档；②画廊网格稿（一大两小三块 + 右上四角星）——构图过关，星待换。
