落地实现步骤（全仓单源封装，彻底干掉刺眼白块）：
1. 封装共享件 VeneraContextMenuArea：接收 menuElements: () -> List<VeneraMenuElement>，取代 androidx.compose.foundation.ContextMenuArea。
2. 底层使用 androidx.compose.material3.DropdownMenu + 自定义深色修饰符：绑定 surfaceContainerHigh 色板、12dp 圆角与 1px 浮岛外边框，天然融入当前深色主题。
3. 统一键盘映射契约：为 VeneraMenuItem 提供可选的 shortcutKey: String? 与 isDestructive: Boolean，全仓一处排版，全局享受右对齐与危险警示样式。
