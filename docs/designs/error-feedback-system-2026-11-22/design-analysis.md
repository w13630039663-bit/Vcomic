# 报错提醒与问题反馈系统 — 设计分析

规格名:`error-feedback-system-2026-11-22` · 日期:2026-11-22
标注口径:**【确定】= 规范文档 / 代码直接可读**；**【估算】= 观感推算**，禁止把估算伪装成确定。

## 1. 页面结构

- 顶栏窗口控制层（`TitleBar` 右上与居中叠层，挂载于 `LocalChromePalette` 作用域内）：
  - 岛屿 A：顶部报错胶囊锚点（居中悬浮，平时隐藏）
    - 状态红点 / 大白话单行摘要 / 未读计数角标 / 下拉箭头
  - 岛屿 B：报错轻量下拉面板（胶囊正下方展开，非全屏居中遮罩）
    - 顶栏操作区：标题 + 全部复制 + 清空 + 关闭
    - 分类筛选行：全部 / 漫画 / 图库 / 系统
    - 报错卡片列表：`LazyColumn` 承载各条 `ErrorItemCard`（主标题 + 人话原因 + 分类标签 + 详情折叠区 + 复制 + 去反馈）
  - 岛屿 C：常驻反馈入口（顶栏最小化按钮左侧）
    - 图标 + 「反馈」文字按钮
  - 岛屿 D：问题反馈与新功能建议面板（反馈入口下方展开）
    - 顶栏操作区 + 双 Tab 滑块（「问题反馈」/「新功能建议」）
    - 表单区：关联报错选择器（仅问题反馈 Tab）+ 标题 + 描述 + 截图附件区（本地选图 + `Ctrl+V` 粘贴）
    - 提交行：剪贴板提示文案 + 主操作按钮（「前往 GitHub 提交」）

## 3. 视觉层次

- **底层背景**：主窗口内容区保持无全屏暗色遮罩（移除原 `DesktopErrorReport.kt:482` 的 `0.42f` 全屏拦截蒙层，点击外部空白区域直接收起浮层）。
- **一级浮层容器（下拉面板 / 反馈面板 / 顶部胶囊）**：沿用 `DesktopGlassCard` / `LocalChromePalette` 透明玻璃或实底对比口径，`1.dp` 发丝描边 + 浮层投影 `vShadow`，暗色深炭磨砂，亮色浅白磨砂，彻底解决原 `palette.elevated` 挂载错位导致的白底突兀问题（确定 · `DesktopErrorReport.kt:496`）。
- **二级内嵌块（报错卡片 / 输入槽 / 截图拖放区）**：同心圆嵌套几何，使用更低透明度二级底色与弱描边，悬停时即时提亮底色并强化描边。

## 5. 响应式视口规则

| 视口档 | 断点 | 重排规则 |
|---|---|---|
| 宽档 | ≥ `900.dp` | 顶部胶囊居中于顶栏，报错面板 `540.dp` 居中展开，反馈面板 `440.dp` 锚定右上角最小化左侧展开 |
| 窄档 | < `900.dp` | 胶囊最大宽压缩至 `240.dp` 防止与顶栏导航/右侧按钮碰撞；下拉与反馈面板宽度按视口自适应留边 `16.dp` |
