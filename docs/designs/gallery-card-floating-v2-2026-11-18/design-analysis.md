# 画廊浮动卡片 v2 — 深度设计分析

## 1. 基线状态（v1 落地后）

组件仍为 `DesktopGalleryCard` 唯一卡 + `DesktopGalleryCardInfoLayout` 统一信息栏。v1 已解决平贴感、雾带裁画、站名黏连、动作入口单一四项。本轮目标是在 v1 基础上把"浮动"从状态切换升级为有厚度的立体对象。

## 2. v1 剩余五项不足（确定值来自源码，估算值来自方案稿视觉判断）

1. **暗色缺体积纵深**：`vShadow` 在暗色档被全局短路（黑楔子 bug 的规避），卡片抬升时底部无投影；仅靠顶光渐变边分层，"浮起"反馈弱。
2. **边框无方向交互**：`borderBrush` 为固定垂直渐变，鼠标在卡面移动时边框亮度不变，缺少 pointer-driven 的受光反馈。
3. **底托纯色平涂**：卡片底托为单色 `Color(0xFF12161F)`，无上亮下暗受光梯度，也无顶边高光刃，缺少物理厚度暗示。
4. **视差单层**：封面仅做 Y 轴微移 + 缩放；右上角胶囊、左上角角标与封面同层，无前后景深关系。
5. **信息栏站标常亮**：站点胶囊深浅两档恒为主题色，满墙排布时形成多处高饱和色块，与"封面为主角"冲突。

## 3. v2 五项优化与工程约束

- **① 环境弥散光 + 双层投影**：
  - 暗色档**不恢复 Skia drop shadow**（违反本仓铁律，会在暗底产黑楔子）。改用 `drawBehind` 自绘向下偏移的柔和弥散光：颜色取主题色低透明（可控），随悬停渐显，边缘靠 brush 渐变自然淡出，无需 blur。
  - 浅色档保留 `vShadow`，悬停 elevation 由 `16.dp` 提到 `20.dp`。
- **② 追光边框**：`borderBrush` 在悬停且指针在卡内时，切换为以 `localMousePos` 为中心的 `Brush.radialGradient`，靠近指针侧被点亮，远端回落到原边框色。坐标与 border modifier 同处一个 Box，系一致。
- **③ 受光渐变底托 + 顶边高光刃**：底托由单色改 `Brush.verticalGradient`（暗：顶 `#1B2231` → 底 `#12161F`；悬停顶 `#222C3D` → 底 `#171D29`），两端用 `animateColorAsState` 平滑。顶边加 1dp 水平渐变高光刃（透明→亮→透明），宽约 70%。
- **④ 三层视差**：封面新增 X 轴 pan（与 Y 轴同为 ±6.5dp 反向）；左上角角标与右上角胶囊用反向微位移（±2.8dp）叠加在现有进入动画上，均走 `graphicsLayer`/`offset` 绘制层，**不进测量**（守住跳位批结论）。
- **⑤ 信息栏悬停唤醒**：站点胶囊常态中性半透明，卡片悬停时过渡到主题色；通过 `DesktopGalleryCardInfo` 新增 `highlightSource: Boolean = false` 形参透传，默认值保证其他调用点零改动。

## 4. 响应式与视口约束

- 沿用 `DesktopWallSpec` 列宽；单卡最小宽度约 156dp，右上角胶囊（约 100dp）与左上角角标不互遮。
- 窄卡（<170dp）站点胶囊保持单行不收缩，画师名自适应省略。
- 所有位移/倾斜/缩放只在绘制层，不改变组件测量尺寸；22dp 尾槽继续恒占测量。
