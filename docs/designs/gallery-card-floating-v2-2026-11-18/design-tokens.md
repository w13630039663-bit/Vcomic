## 2. 尺寸与几何 Token

- 同心圆角：Outer `15.dp`（由 v1 `14.dp` 微调，估算） / Padding `5.dp` / Inner `10.dp`；`15 - 5 = 10` 成立。
  - **兼容约束**：若判据钉死 `14.dp`/`4.dp` 不在此改列内，则本轮维持 v1 的 `14/4/10`，仅做视觉层优化。
- 顶边高光刃：高 `1.dp`，宽 = 卡片宽 × `0.7`，水平渐变。
- 追光边框：`1.dp`，追光半径 `210.dp`（估算）。
- 封面视差：`±6.5.dp`（X/Y 同档，估算）；角标与胶囊反向 `±2.8.dp`（估算）。
- 抬升：`-7.dp`（估算，v1 为 `-5.dp`）；缩放置身 `1.022`（v1 为 `1.02`）；倾角 `±5°`（v1 为 `±4.5°`）。
- 环境弥散光：向下偏移 `8.dp`，随悬停渐显，alpha 上限约 `0.34`（估算）。

## 3. 字阶 Token

沿用 v1：标题 `13.5.sp / 560`、画师 `12.5.sp / 450`、站标 `10.sp / 600 / +0.04em`、角标 `11.sp / 600 / tnum`。本轮不改动字阶。

## 4. 动效 Token

- 悬停过渡：`260ms`，`cubic-bezier(0.22, 1.28, 0.36, 1)` 等价低阻尼弹簧。
- 站标悬停唤醒：`200ms` 平滑过渡。
- 環境光渐显：`260ms`，与抬升同步。
- 其余（按钮阶梯 `0/30/60ms`、按压 `0.97`、入场弹簧）沿用 v1 不变。
