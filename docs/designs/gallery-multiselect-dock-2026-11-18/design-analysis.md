# 画廊与漫画双域多选与批量操作方案分析 — 2026-11-18

## 1. 业务现状与多选全景

在 Venera 桌面端，用户在**画廊域 (Gallery / Pixiv / Booru)** 与 **漫画域 (Comics / Explore / Favorites / History)** 均有高频的批量操作需求。

| 维度 | 画廊域 (Gallery) | 漫画域 (Comics) |
|---|---|---|
| **基本实体** | 单张插画 / 图库 Post (`DesktopWallCardModel`) | 漫画作品集 / 本子 (`ComicCard` / `ComicEntry`) |
| **卡片比例** | 1:1 方图 或 瀑布流自由比例 | 3:4.05 竖版书籍比例 |
| **核心批量动作** | 1. 批量保存图片（原图/1200大图/直链提取）<br>2. 批量加入图库收藏<br>3. 复制站方/直链 URL<br>4. 浏览器批量打开 | 1. 批量下载章节（下载整本 / 下载最新话 / 选话下载）<br>2. 批量归档分类收藏夹（追更/完结/待看）<br>3. 批量标记已读/未读<br>4. 批量清除历史/删除本地离线缓存 |
| **痛点现状** | 卡片虽支持勾选，但**无底部操作栏，选后无出口** | 仅部分本地收藏页有基础工具条，主探索/搜索无统一悬浮交互 |

---

## 2. 统一设计语言：双域悬浮坞与操作弹窗

为避免两端操作体验割裂，采用统一的 **VDDS 悬浮总控坞 (Floating Multi-Select Dock) + 场景化批量弹窗 (Batch Modal)** 规范：

### 2.1 悬浮总控坞 (Floating Dock) 结构规范
- **高度与形态**：固定 52dp 胶囊坞，悬浮在屏幕底部中央（距底 24dp），背景使用 85% 深度毛玻璃，阴影采用 36px 漫反射柔光。
- **公共左区（状态与整体控制）**：
  - `已选择 N 项`：胶囊 Badge。
  - `全选` / `反选` / `取消 (✕)`：点击反馈时间 <= 150ms。
- **差异化右区（按业务域自适应 Action 药丸）**：
  - **画廊域**：`📥 批量下载 (N)` (主色 CTA)、`❤️ 收藏`、`🔗 复制链接`、`⋯ 更多操作`。
  - **漫画域**：`📥 批量下载话数` (主色 CTA)、`📁 移入收藏夹`、`👁️ 标为已读`、`⋯ 更多/删除`。

### 2.2 批量任务弹窗 (Batch Dialog) 规范
- **通用顶部**：已选作品横向缩略带 (Reel Scroll)，单张悬浮可点击 `✕` 剔除误选项。
- **画廊域弹窗 Tab**：
  1. `批量下载`：画质选择（原图最高清 / 1200大图 / 自动适应）、跳过已存在、按画师建子文件夹。
  2. `收藏归档`：图库收藏夹选择、新建文件夹。
  3. `链接导出`：复制站方网页 URL、复制图片直链、提取标签。
- **漫画域弹窗 Tab**：
  1. `批量下载`：下载范围单选（全本下载 / 仅下载最新话 / 仅下载首话试读）、并发数与排队提示。
  2. `收藏分类`：多选目标分类标签（追更 / 完结 / 稍后再看 / 自定义分组）。
  3. `批量维护`：标记全部已读、清除单本缓存、移出历史或本地库。

## 3. 防抖、限流与安全规范

1. **画廊图床限流保护**：批量下载插画时严格继承 `DesktopImagePipeline` 3 并发限制与 429 自动冷却退避队列。
2. **漫画接口节流保护**：批量提取漫画章节时，单源请求间隔 >= 300ms，防止瞬时并发封 IP。
3. **防误触警告**：批量操作超过 20 部漫画或在浏览器批量打开超过 10 个网页时，必须进行数量二次确认。
