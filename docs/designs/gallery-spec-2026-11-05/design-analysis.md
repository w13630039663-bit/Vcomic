## 一、 页面整体布局与架构解构

### 1.1 视口与基础骨架
- **目标窗口基准**：桌面端标准窗口（1280dp × 800dp 至 1920dp × 1080dp 及以上）。
- **页面主框架划分**：
  1. **左侧固定/折叠导航轨 (Desktop Navigation Rail)**：
     - 折叠态宽度：`60dp` [确定值]
     - 展开态宽度：`200dp` [确定值]
     - 定位属性：窗口左侧绝对固钉，占满视口全高 `100vh` [确定值]
  2. **主内容滚动舞台 (Main Scroll Stage)**：
     - 水平对齐：左侧紧贴侧栏，右侧延伸至窗口边缘，无硬性最大宽度钳制（流式弹性铺满）[确定值]
     - 内容内边距：两侧各 `20dp`（`screenHorizontal`）[确定值]，顶部 `16dp`，底部 `32dp` [确定值]
     - 滚动属性：垂直方向单一流畅滚动容器，内部横向架子自持横向触摸/手势滑动轨 [确定值]

### 1.2 纵向区域层级与视觉流（从上至下完整清单）

1. **全局桌面顶栏 (Desktop Topbar / Header)** [补充遗漏]：
   - 尺寸：固定高度 `52dp` [确定值]。
   - 内部结构：
     - 源切换分段器（图库站 / Pixiv，高度 32dp）[确定值]；
     - 居中满宽搜索框（高度 `36dp`，最小宽 `280dp`，圆角 `10dp`，内嵌 `Ctrl+K` 等宽胶囊）[确定值]；
     - 右侧操作把手（刷新按钮 32dp、账号/登录入口 32dp、设置中枢齿轮 32dp）[确定值]。
2. **第一屏：发现带二合一 Bento (Find Band Bento)**：
   - 容器规格：Bento 容器，高度锁定 `276dp` [确定值]（含内边距与标题）。
   - 双列划分：左列「人气标签长图流」（宽度占比 `1`），右列「推荐画师流」（宽度占比 `1.2`），中间带 `1dp` 垂直分割线 [确定值]。
   - 两侧均悬浮 `28dp × 28dp` 半透明圆形左右翻页按钮（`‹` / `›`），消灭系统灰色横条 [确定值]。
3. **第二屏：关注新作横滑架 (Following Works Shelf)** [修正尺寸]：
   - 容器规格：Bento 容器，高度 `198dp` [确定值]。
   - 内容：单卡宽度 **172dp** [确定值]（原估算 200dp 已纠正），封面高度 **112dp** [确定值]，圆角 `12dp`。
   - 字段：缩略封面 + 作品标题（12sp）+ 画师昵称与发布时间（如“12分钟前”，10.5sp 灰色）。
4. **第三屏：统一排行榜架 (Ranking Shelf)** [修正尺寸]：
   - 容器规格：Bento 容器，高度 `220dp` [确定值]。
   - 榜单分段：日榜 / 周榜 / 月榜 / 新人 / 原创（高度 28dp）[确定值]。
   - 单卡规格：宽度 **172dp** [确定值]，封面高度 **112dp** [确定值]。
   - 排行徽标：左上角 `rank-no`（尺寸 `20dp × 18dp`，半透明黑底带 1px 描边，加粗白色数字）[确定值]。
5. **第四屏：pixivision 特辑杂志架 (pixivision Magazine Shelf)** [修正尺寸]：
   - 容器规格：Bento 容器，高度 `400dp` [确定值]。
   - 左侧主推特辑大卡：宽度 **640dp** [确定值]（原估算 520dp 已纠正），高度 **340dp** [确定值]（原估算 200dp 已纠正），字号 `22sp` 大标题，右上角带 `特辑` 主色徽章。
   - 右侧纵向列表：2 张次级文章横向卡片，平分右侧剩余空间。
6. **核心主体：为你推荐作品墙 (For You Immersive Wall)**：
   - 布局范式：自适应等宽网格（Equal-width Grid），间距 `16dp` [确定值]。
   - 伸缩行为：随窗口宽度从 4 列（小窗）自然延展至 7 列（超宽屏），卡片最小宽度 `210dp` [确定值]。
   - 卡片比例：标准插画为 1:1 方图居中裁剪；横图/宽幅插画触发 `span 2`，呈现 2:1 宽高比，高度恰好等于单格方图高度 [确定值]。
   - 交互悬浮：右上角轻量半透明毛玻璃动作坞（`♥` 收藏、`⬇` 下载、`✓` 加选、`⋯` 更多）[确定值]。
   - 上下文菜单：指针右键弹出暗色深沉浮层（宽 `216dp`，圆角 `10px`），包含图标、热键和危险隔离操作 [确定值]。
7. **浮动操作把手 (Floating Action Buttons)** [补充遗漏]：
   - 悬浮于视口右下角（`bottom: 24dp, right: 24dp`），圆形直径 `44dp` [确定值]，阴影 `6dp`，包含回到顶部（`↑`）与即时刷新（`↻`）。
8. **二级页面：pixivision 文章详情页 (Article Detail Screen)** [补充遗漏]：
   - 顶栏：返回把手 + 特辑类别徽标（高度 22dp）+ 发布日期（11.5sp）+ 站方打开按钮 [确定值]。
   - 文章大标题：`font-size: 32sp; font-weight: 700; line-height: 1.3; letter-spacing: -0.4sp` [确定值]。
   - 导读段落 (Lead)：`font-size: 14sp; line-height: 1.8; max-width: 820dp` [确定值]。
   - 作品单元流 (Work Unit Stream)：作品大图（原图自然比例大图呈现）+ 画师信息条（头像 32dp、画师名、作品名、搜画师按钮、收藏按钮、下载按钮）+ 配文说明文字 [确定值]。
   - 底部相关特辑推荐轨 (Related Rail)：单卡宽 **236dp** [确定值]，缩略图高 **132dp** [确定值]，特辑标题 12sp。

## 三、 审查修正与不确定项目说明

### 3.1 审查纠错总结
1. **纠正了关注新作卡与排行榜卡的尺寸**：设计稿真实类名 `.r-card` 宽度为 `172px`，封面 `.r-thumb` 高度为 `112px`，纠正了原估算值 200dp 与 130dp 的偏差。
2. **纠正了 pixivision 杂志特辑主卡尺寸**：设计稿真实类名 `.pv-feature` 宽度为 `640px`，高度为 `340px`，纠正了原估算值 520dp × 200dp 的偏差。
3. **补齐了二级文章页的全部关键规格**：补充了文章顶栏元信息、大标题排印参数（32sp/-0.4sp 字间距/1.3 行高）、导读段落（14sp/1.8 行高/820dp 限制宽）、作品单元（30dp 间距）、以及底部相关推荐轨（236dp 宽）。
4. **补齐了 Booru 标签维度舱与分页舱规格**：完善了 4 列网格（画师、角色、系列、通用）及每页数量分段与键盘快捷键定义。

### 3.2 遗留的环境与实现限制
- **[未知值] 真实插画的渐进加载占位图策略**：原设计稿使用纯 CSS 渐变色块（`.ph.v1` ~ `.ph.v8`）代表加载中，软件实际开发中需通过 Coil 接入统一 Shimmer 骨架或主色调提取占位。
- **[未知值] 极端小窗口（窗宽低于 1024dp）时的侧栏与 Bento 响应策略**：设计稿在 1400dp~1920dp 表现完美。在低于 1024dp 时，双列 Bento 建议自动折叠为单列上下排布，或由 Compose `BoxWithConstraints` 动态断点调度。
