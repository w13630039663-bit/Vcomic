# 安装器视觉方案 v3 · 原生云母玻璃风

日期：2026-11-22　规格名：`installer-wizard-v3-2026-11-22`

## 用法

双击打开 `index.html`（单文件自包含，无外部网络依赖）。
顶部悬浮调试条分两组：
- **主流程**：`启动 / 选项 / 安装中 / 完成`
- **扩展态**：`旧版迁移 / 进程冲突 / 取消弹窗 / 安装失败 / 修复/卸载`

同时支持重播启动动效、切换 `浅色 / 深色` 主题与 `首次安装 / 覆盖升级` 模式。

## 设计定位

- **视觉体系**：对齐 VComic 桌面端现代质感（原生云母玻璃风，浅色默认 + 深色切换，官方强调色浅 `#0A63F6` / 深 `#0A84FF`）。
- **窗口型制**：640×440 居中聚焦紧凑窗，点击「自定义目录」时底部 300ms 丝滑延展。
- **启动图形**：项目定稿「圆笔 V + 摊开书」标志拆解为精确 31 片矢量几何片，800ms 由中心向两翼逐段生长。
- **安装进行中**：五幕介绍（多源聚合阅读 / 双页沉浸视图 / 标签筛选检索 / 本地离线缓存 / 本地数据独立）各配专属分层玻璃矢量插画，支持 6s 自动轮播与点击指示点快速切换。
- **全生命周期业务态**：覆盖旧版 MSI 迁移提示、进程占用提示、安装中毛玻璃取消确认弹窗、磁盘/权限/占用三种失败回退态，以及已安装时的修复/卸载维护态。
- **业务保真**：沿用 `packaging/venera-installer.iss` 口径（`VComic 2.1.1`、免管理员 `%LOCALAPPDATA%\venera-desktop`、数据根目录 `%LOCALAPPDATA%\venera` 独立保留）。

## 必保动效参数对照

| 环节 | 参数 |
|---|---|
| 启动图形逐段生长 | `800ms`，`31 片` |
| 字标出现 | `300ms` 放大淡入 |
| 收拢进主界面 | `300ms` |
| 背景缓慢漂移 / 呼吸 | `6s` / `10s` |
| 安装插画浮动 | `2s`，纵向 `±33` |
| 三幕轮播 | `6s`（`1s` 入 / `4s` 持 / `1s` 出） |
| 目录面板展开 | `300ms` |
| 按钮按压 | `120ms`，`0.97` |
| 进度推进 | `12s`，严格单调曲线 |
