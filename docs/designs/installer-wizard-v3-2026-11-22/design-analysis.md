# VComic 桌面端安装器 v3 — 设计分析

规格名：`installer-wizard-v3-2026-11-22` · 日期：2026-11-22
标注口径：**【确定】= 源码 / 规范文档 / HTML 方案稿直接可读**；**【估算】= 视口与交互推算**。

## 1. 页面结构

- 根容器：640×440dp 无边框圆角云母窗口（`RoundedCornerShape(20.dp)` + 1dp 玻璃高光描边 + 软阴影）
  - 岛屿 A · 环境光层（底层独立合成层）：漂移极光团（6s）与呼吸光晕团（10s），不参与内容重排
  - 岛屿 B · 极简窗口标题栏（40dp 高）：左侧状态点与「VComic 安装程序 · 2.1.1」（Splash 期隐藏），右侧最小化 / 关闭按钮
  - 岛屿 C · 主画布容器（`padding = horizontal 28dp, bottom 24dp`）：
    - **品牌头（Splash & Ready 共享）**：白色圆角图标徽章 + `VComic v2.1.1` + 副标题；Splash 期居中（`paddingTop 76dp`），1250ms 起 300ms 收拢为顶部水平品牌头
    - **主流程 4 幕**：`Splash` → `Ready`（含可展开 300ms 目录面板 + 覆盖升级横幅） → `Installing`（2s ±33 浮动插画 + 6s 五幕轮播 + 12s 单调进度条） → `Done`（安装摘要 + 立即启动）
    - **扩展 4 态**：`Migration`（旧版 MSI 迁移确认）、`Conflict`（进程占用提示）、`Error`（磁盘不足 / 权限受限 / 文件占用三态切换与回退）、`Uninstall`（修复 / 卸载双选维护）
  - 岛屿 D · 内嵌毛玻璃遮罩弹层（Overlay）：安装进行中点击关闭触发「确认取消安装？」居中卡片，带背景高斯模糊遮罩

## 3. 视觉层次

1. **云母底与环境光层**：浅色底 `#F9FBFE`（78% 不透明）配极淡蓝青极光，深色底 `#161B24`（78% 不透明）配低饱和蓝紫光晕；桌面端按 `AGENTS.md` 走既有 `vShadow` / 云母半透明描边管道。
2. **内层表面卡片**：所有摘要卡片、目录面板、进度卡片与维护选项均采用半透明表面 + 1dp 细描边，圆角严格满足同心圆几何。
3. **强调色单源**：全站唯一装饰色为官方蓝（浅 `#0A63F6` / 深 `#0A84FF`），仅用于主按钮、进度条、激活指示点、选中态描边与图标局部点缀；状态语义色仅用于升级警告（琥珀）、完成（翠绿）与错误/危险（红）。
4. **暗浅双态差异**：浅色模式下内层卡片靠高亮度白底（72%~90%）与浅灰细描边区分层次；深色模式下内层卡片提亮至 `#222936`（68%~85%）并改用微弱白透描边（9%~16%）。
