# 薇薇待机态 · 搜索空态设计分析

- 稿源：主人定稿 `venera.html`（搜索待机态吉祥物预览，本仓外）。本稿为其逆向规格，验收目标即该稿。
- 落位：漫画搜索页空态分支（`DesktopSearchScreen.kt` `emptyNote != null`），替换原孤立提示行。

## 区域结构

- 中央空态区：竖排居中两件——吉祥物（64×64 基准，命中区外扩 6px 圆角 16）+ 提示语（间距 18px）。
- 提示语文案与字号一字不动（`desktopComicSearchEmptyNote` 产出，测试钉死）。

## 形状解构（100×100 视口，全部确定值）

- V 臂：折线 `M27,19 L50,58 L73,19`，描边 15.5，圆头圆角。
- 左翼（书页）：`M50,68.5 Q31,57.5 13.5,63.5`，描边 13.5；右翼镜像 `Q69,57.5 86.5,63.5`。
- 身体（junction）：`M39,48 L61,48 L64,68 Q50,76 36,68 Z`，填充，连接 V 尖与书页。
- 双眼：胶囊 4.1×10.2，rx 2.05，左 x=42.15、右 x=53.75，y=51.7。
- 底部中央缺口：竖线 `(50,72.5)→(50,80.5)`，宽 2.6。
- 眼与缺口是 mask 真镂空（透底），非叠色；Compose 对应 `BlendMode.DstOut` + 离屏层。

## 状态机（主人定稿的核心，不得简化）

- 安静待机：呼吸 + 随机慢眨眼 + 偶发低头看书。
- 我在听：输入框聚焦——抬眼看上方（第一刀未接线，遗留点）。
- 打盹：15s 无活动自动进入；呼吸放慢、透明度降、身体下沉、眯眼（底边锚定）。
- 轻点：打盹时唤醒；清醒时慢眨眼一次。
- 视线跟随：指针活跃期（2.6s 窗口）双眼微随鼠标；打盹归零。

## 应用内接线口径

- 活动信号：`query` 变化即重置打盹计时（走组件 `awakeKey` 参数）；指针移动/点击组件区同样重置。
- 调参抽屉是演示工具不进应用；参数取定稿默认值固化。
