## 动效令牌

- 呼吸：周期 4.8s（打盹 ×1.35，平滑跟随 rate 2.2）；翅尖抬升 = breath×1.4，V 顶张开 = breath×0.7（breath = 0.5−0.5cos 相位，连续累加不跳帧）。
- 慢眨眼：间隔 3.8–6.8s 随机；曲线 = 110ms smoothstep 闭至 0.10 + 40ms 保持 + 140ms easeOutCubic 开。
- 打盹：延迟 15s；透明度 ×0.72；下沉 1.3 视口单位；眼高目标 0.42（底边锚定混合 rate 3.8）；呼吸放慢 1.35×。
- 视线：偏移上限 ±1.6 / ±1.2 视口单位；活跃窗口 2.6s；归一化半径 = 窗口长边 ×0.34；阻尼 rate 3.4。
- 阻尼公式：`cur + (target−cur)×(1−exp(−rate·dt))`，dt 上限 0.05s。
- 聚焦「我在听」：透明度 +0.14（上限 0.55）、抬眼 −0.75（第一刀未接线，见 analysis）。
