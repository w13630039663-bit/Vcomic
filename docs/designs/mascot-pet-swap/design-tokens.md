# 薇薇桌宠换芯 · 设计令牌（全部确定值，逆向自 v3 稿）

## 颜色

- 剪影：主题自适应 `textPrimary`（= onSurface），透明度基线 0.84、打盹 0.62。
- 星：`#FBBF24`（P5 进行中档）；心：`#F87171`（收藏/到手/归来）；迎候与轻点短线走主题前景。
- 感叹杠：星色 + 心色圆点（异常档脉动）。
- 双色靛蓝支线不做（主人令）。

## 尺寸与节奏

- 视口 120×120 等比缩放；折叠轨 46px、展开档 124px。
- 呼吸周期：待机 4.8s / 深夜 5.6s / 打盹 6.4s，相位连续累加不跳帧；呼吸带二级谐波 0.06。
- 慢眨眼：3.5–6s 随机，曲线 65ms 闭 + 25ms 保持 + 75ms 开（smoothstep / easeOutCubic）。

## 弹簧与阻尼（二阶弹簧 k/阻尼比）

- 整体缩放 210/14；身体沉浮 110/13；右臂 150/12；书页翼 170/12.5。
- 姿态目标切换的阻尼率：身体旋转与左臂 7.5、眼高 8.5（打盹 3.8）、弯月混合 10、委屈混合 8.5、视线 4.2、装饰 6.5–11、剪影透明度 4.5。
- 冲量：轻点 scale 1.11/0.89 + vel(-0.8, 1.4) + ty -36 + 臂 165°/s；收藏 ty -68 + scale(-0.65, 0.95)；归来 ty -46 + scaleY 0.55；害羞 ty -30。
- 指数阻尼公式 `cur + (target−cur)×(1−exp(−rate·dt))`，dt 上限 0.05s。
