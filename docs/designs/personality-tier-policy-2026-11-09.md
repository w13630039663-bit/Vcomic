# 分级设计语言（个性档规矩 · 2026-11-09）

主人定调：**部分页面可以个性化，没必要全部页面都太克制。**

## 两档制

| 档 | 适用 | 规范出处 | 允许 |
|---|---|---|---|
| **底座档（克制）** | 全站默认：首页 / 收藏 / 搜索 / 探索 / 详情 / 设置 / 侧栏 / 工具栏 | `macos-style-2026-11-07` 全套 Token | 维持现纪律：accent 唯一装饰色、chip 禁彩、三档阴影封顶 |
| **个性档（放开）** | 白名单页面，目前仅「阅读历史」 | 本目录 `history-source-filter-2026-11-09/`（persona 稿） | 源身份色、辉光投影、渐变大字、全幅封面流、时间轴轨 |

## 个性档边界（放开 ≠ 无政府）

1. **壳层不放开**：统一工具栏、发丝线、红绿灯、推压钮几何仍走母稿；个性只发生在内容区。
2. **文案铁律不放开**：主标题 ≤6 字、副标题 ≤15 字、零拟人零比喻（`AGENTS.md` UI 文案节仍最高优先）。
3. **装饰色收口**：个性档允许「源身份色」这一类**语义色**（每源一色，色随源走，不乱铺）；无语义的纯装饰仍守 accent 唯一。
4. **判据不放开**：门控 / 打码 / 写口 / 两按确认等业务判据与母稿完全同源，个性档只换皮。
5. **进白名单要主人点头**：新页面想进个性档，先出稿再由主人拍板；不自动扩散。
