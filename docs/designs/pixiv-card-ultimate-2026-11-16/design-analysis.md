## 1. 原型视觉特征与解构

用户提供的原型核心诉求是将原先扁平静态的网格卡片，重塑为具备**三维物理景深、智能长图漫游、动态色彩光晕与阶梯交互浮层**的现代高质感作品卡片。

### 1.1 视觉层级解构（从底至顶）

```
[Level 0] 容器阴影与动态光晕 (Dynamic Glow & Ambient Shadow)
    └── 静态沉底深阴影 (0 10px 30px -10px rgba(0,0,0,0.6))
    └── 悬停自适应色晕 (0 20px 40px -10px var(--glow-color, rgba(255,255,255,0.1)))

[Level 1] 卡片底座容器 (Card Container)
    └── 背景：0xFF161618 (半透明深黑微质感)
    └── 边框：1px 0x0AFFFFFF 微光描边 + 0x1AFFFFFF 悬停高亮
    └── 圆角：16dp (大型同心圆角)
    └── 3D 偏转：rotationX (±5°), rotationY (±5°), scale (1.02)

[Level 2] 封面视口 (Cover Viewport)
    └── 裁切：顶部圆角 16dp，底部直角
    └── 底层图片：默认 1.06x 微放大，跟随指针 Y 轴上下漫游平移 (Pan & Scan ±6%)
    └── 底部渐隐：48dp 线性渐变 (Transparent -> 0xFF161618)，无缝融进信息区
    └── 悬停标签弹现：左上角 12dp 内衬，3枚药丸阶梯弹入 (delay 35ms / 70ms / 105ms)

[Level 3] 动态光斑与微反光 (Specular Glare Layer)
    └── 径向高光跟随鼠标实时坐标扩散 (径向渐变 220px，alpha 0.12 -> 0)

[Level 4] 信息层与作者行 (Info Content Area)
    └── 标题文本：14sp SemiBold，单行截断
    └── 作者行：18dp 圆形头像 + PIXIV 品牌蓝徽标 + 画师名称 (12sp 次级灰)
    └── 右键菜单与选卡状态完整穿透保持
```

## 2. 核心交互机制详解

### 2.1 3D 物理倾角（3D Tilt）
- **坐标归一化**：当指针在卡片内移动时，计算相对中心的归一化偏移：
  - `percentX = (x - width / 2) / (width / 2)`，区间 `[-1.0, 1.0]`
  - `percentY = (y - height / 2) / (height / 2)`，区间 `[-1.0, 1.0]`
- **旋转角度映射**：
  - `rotationX = percentY * -5.0f`（鼠标偏上，卡片向上仰视倾斜）
  - `rotationY = percentX * 5.0f`（鼠标偏右，卡片向右侧倾斜）
  - `scale = 1.02f`
- **回正衰减**：指针移出后，通过 `spring(dampingRatio = LowBouncy, stiffness = Medium)` 平滑归零。

### 2.2 封面智能漫游（Pan & Scan）
- **问题背景**：网格方图（1:1）经常裁掉竖直长图的头尾精彩部分。
- **漫游映射**：
  - 基础缩放保持 `1.08f`（预留上下移动安全余量，防止露出底边）；
  - 根据指针在封面区域内的垂直比例 `yPercent = y / imageHeight`（`0.0` 至 `1.0`）；
  - 垂直偏移量 `translateY = (0.5f - yPercent) * 12.dp`；
  - 鼠标移至卡片上半部时画面微向下平移展现顶部，移至下半部时平移展现底部，实现“视线跟随”探索感。

### 2.3 标签药丸阶梯浮现（Staggered Tags Float）
- **常态**：隐藏（`alpha = 0f`, `translateY = -8dp`）。
- **悬停态**：浮现（`alpha = 1f`, `translateY = 0dp`）。
- **错落延迟**：前 3 枚标签依次应用 `35ms * index` 延迟与弹簧曲线，错落浮现，收回时同步迅速淡出。

## 3. 业务与技术边界

1. **多选与内容守卫兼容**：
   - 选中态：卡片右上角保留高亮选卡角标（✓），边框切换为主题强调色（`tokens.color.primary`）；
   - 打码态：当作品命中敏感守卫时，封面正常覆盖磨砂遮罩并禁用长图漫游。
2. **右键菜单完整保持**：
   - 原右键上下文菜单（查看大图、选卡、复制、在站方打开、查看画师、屏蔽画师）完全保留。
3. **文案规范**：
   - 严格遵循主标题 ≤ 6 字、副标题 ≤ 15 字，无文学修辞。
