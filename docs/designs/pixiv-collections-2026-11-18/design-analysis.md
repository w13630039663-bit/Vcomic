# 珍藏册(pixiv Collections)逆向分析 — 2026-11-18

来源:主人提供 pixiv 官方截图三张(发现页 / 珍藏册详情×2 / 功能简介)。
模式:**Refinement**——画廊 pixiv 域内新增模块,沿用既有 VDDS 语言,不重设计。

## 官方信息盘点

**发现页**(pixiv 站内页)
1. 简介横幅:功能说明 + 「尝试创建」/「查看详情」+ 测试版说明。
2. 筛选标签行:左侧「筛选」+ 一排彩色标签胶囊(横向滚动,右端渐隐)。
3. 「推荐珍藏册」rail:封面拼贴卡 + 标题 + 创建者头像名 + 心形收藏钮。
4. 「大家的珍藏册」rail(同上)。
5. 「#标签 相关推荐珍藏册」rail(同上,节头带标签名)。
每节右上「查看全部」。

**珍藏册详情页**(官方移动版式)
1. 顶部白条居中标题 + 右上创建者卡(头像/名/关注钮)。
2. 封面墙:规则 3 列方形网格,每格底部画师名胶囊;另有拼贴混排变体(不规则跨行)。
3. 墙下信息块:描述、标签行、心形收藏数/分享/更多、创建日期。
4. 创建者一览:小封面拼贴 + 「查看珍藏册一览」。
5. 评论区。

**收藏入口**:收藏的珍藏册挂在用户主页的「珍藏册」栏。
