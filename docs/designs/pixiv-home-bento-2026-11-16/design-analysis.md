# Pixiv 站点首页 Bento 布局重构 · 逆向分析与视觉解构

> 依据：用户提供的图一（当前 Pixiv 首页实际结构截图，1920×1080 视口）与图二（目标布局线框架构图）。
> 目标：将图一分散的多排横向滚动带（人气标签、推荐画师、关注新作、排行榜、Pixivision、为你推荐）重构为图二的高效 Bento 网格看板 + 通栏流布局，无损保留所有业务逻辑与数据接口。
> 标注标准：所有数值严格标注「确定」（源自当前已上线代码与标准 Token）或「估算」（基于线框图几何推算），禁止伪装。

## 1. 结构变迁与信息架构解构

### 1.1 原版布局（图一）痛点分析
1. **视觉重心过散**：原版由 5 组横向滑轨堆叠而成（标签带、画师带、新作带、榜单带、Pixivision 带）。每一排都是单一的横向卡片，视觉层级扁平，缺乏首屏主视觉焦点。
2. **首屏空间利用率低**：标签与画师并排但各自带有冗余的长滑轨空白；Pixivision 特辑被压在第 4 屏，用户难以在首屏快速获取高价值专题内容。
3. **内容节奏单调**：横排列表连续出现 4 次，导致桌面端滚轮浏览疲劳度较高。

## 2. 区域解构与尺寸比例规范

| 区域划分 | 宽度占比 | 容器高度 | 内部解构 | 依据 |
|---|---|---|---|---|
| **顶部精选看板（左）** | 约 68% (弹性 `weight(0.68f)`) | 固定 480dp | 上部 Hero 主视觉（300dp）+ 下部 2 张水平等分子特辑卡（164dp） | 估算（图二比例换算） |
| **推荐画师看板（右上）** | 约 32% (弹性 `weight(0.32f)`) | 固定 280dp | 垂直排列 3 组推荐创作者（头像 44dp + 双行文本 + 关注按钮） | 估算 |
| **热门标签看板（右下）** | 约 32% (弹性 `weight(0.32f)`) | 固定 184dp | 双行胶囊标签流（FlowRow 自动折行，单标签高 32dp） | 估算 |
| **关注新作通栏（中）** | 100% 满宽 | 约 210dp | 标题栏 + 单行横向网格（单卡 16:9 画幅，5 列均分展示） | 估算 |
| **为你推荐瀑布流（底）** | 100% 满宽 | 自适应无限高 | 多列自适应不等高瀑布流（保持插画自然长宽比，非死板方块） | 确定（图二明确为参差错落瀑布流） |

## 3. 视觉层次与表面材质规范

遵循 `better-ui` 与全仓深色规范：
1. **背景底面（Window Host）**：采用 `#18181A`（或桌面纯黑档 `#000000`），保证最深底色不反光。
2. **Bento 容器外壳（Level 1 Surface）**：
   - 底色采用 `#222226`（微弱高亮），给整个大块建立分组轮廓。
   - 描边：`1dp solid rgba(255, 255, 255, 0.08)`，不使用大范围弥散阴影，靠结构描边区分表面。
   - 圆角：外圆角严格为 `16dp`。
3. **内容卡片表面（Level 2 Surface）**：
   - Hero 卡与子作品卡底色为 `#2A2A30`。
   - 图片边界遵循 `better-ui` 准则：`1px outline inset by 1px`，深色使用 `rgba(255, 255, 255, 0.10)`，消除边界灰雾。
   - 内圆角：严格为 `10dp`（符合同心圆法则 `Outer 16dp = Inner 10dp + Padding 16dp` 之光学补偿）。
4. **悬停与反馈**：
   - 鼠标悬停卡片上浮 `translateY(-2dp)`，描边加深至 `rgba(255, 255, 255, 0.16)`。
   - 按压时缩放至 `scale(0.96)`，时长 150ms，缓动 `cubic-bezier(0.2, 0, 0, 1)`。
