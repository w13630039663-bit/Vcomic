# Pixiv 作品详情页空间画廊 · Design Tokens (多图沉浸翻页版)

> 依据：网页源码设计标准、`better-ui` 规范以及本仓桌面端设计系统。
> 几何准则：严格遵循同心圆法则 `Outer Radius = Inner Radius + Padding`。
> 动效准则：遵循 150ms 弹性反馈、`0.96` 按压缩放、轮播弹性曲线 `cubic-bezier(0.175, 0.885, 0.32, 1.275)`。

---

## 1. 颜色与材质 Token

| Token 名称 | CSS 变量 / 属性 | 色值 | 用途与依据 |
|---|---|---|---|
| **底板深黑** | `--bg-dark` | `#030303` | 空间容器基底层 |
| **毛玻璃卡片底色** | `--glass-bg` | `rgba(25, 25, 30, 0.65)` | 65% 透明度深钛黑，用于五大 Bento 岛屿 |
| **主文本色** | `--text-main` | `#F5F5F7` | 作品标题、画师昵称、操作按钮文字 |
| **次级文本色** | `--text-sub` | `#86868B` | 统计信息、发布时间、副标题、徽章辅助字 |
| **翻页按钮底色** | `--nav-btn-bg` | `rgba(20, 20, 20, 0.60)` | 悬浮切页圆形按钮底色 |
| **缩略图导轨底色** | `--thumb-nav-bg`| `rgba(20, 20, 20, 0.60)` | 底部缩略图导轨半透磨砂底色 |
| **缩略图激活描边** | `--thumb-border-active` | `#FFFFFF` | 当前正在查看的缩略图 2dp 纯白外框 |
| **玻璃微光边框** | `--border-glass` | `rgba(255, 255, 255, 0.08)` | 卡片默认描边，防止边缘模糊丢失 |
| **悬浮高亮边框** | `--border-glass-hover` | `rgba(255, 255, 255, 0.15)` | 卡片鼠标悬停或激活时的聚焦描边 |
| **画框外发光** | `--shadow-frame` | `0 20px 40px rgba(0,0,0,0.6)` | 核心原图下方画框阴影 |

## 2. 尺寸与间距 Token

| 参数类型 | Token 名称 | 确定数值 | 几何依据 |
|---|---|---|---|
| **外壳卡片圆角** | `--radius-card-outer` | `24dp` | 五大 Bento 玻璃卡片统一外圆角 |
| **主图卡内边距** | `--pad-card-main-image`| `16dp` | 留出画廊相框与轮播轨道的内边距 |
| **核心图片圆角** | `--radius-image-main` | `8dp` | 内部完整展示插画圆角 |
| **悬浮翻页按钮尺寸** | `--size-nav-btn` | `50dp` | 圆形翻页箭头按钮直径 |
| **缩略图尺寸** | `--size-thumb-item` | `40dp` | 底部 Mini-map 单张缩略图宽高 (1:1) |
| **缩略图圆角** | `--radius-thumb-item` | `8dp` | 缩略图圆角 |
| **缩略图激活缩放** | `--scale-thumb-active`| `1.10` | 激活缩略图光学突出感 |
| **卡片间物理间距** | `--gap-bento-grid` | `24dp` | Bento Grid 列与行之间的物理隔离缝隙 |

## 3. 字体排印 Token

严格执行全仓规矩：**主标题不超过 6 个字，副标题不超过 15 个字**。

| 级别 | Token 别名 | 字号 / 行高 | 字重 | 实例与字数约束 |
|---|---|---|---|---|
| **作品大标题** | `--type-work-title` | `24sp` / `30sp` | ExtraBold (800) | 限制最多 6 字主标题或截断 |
| **画师昵称** | `--type-author-name` | `18sp` / `24sp` | Bold (700) | 画师昵称 |
| **小分区标题** | `--type-section-title` | `13sp` / `18sp` | SemiBold (600) | `评论` / `相关作品` (≤6字) |
| **页码指示器** | `--type-page-indicator`| `13sp` / `18sp` | SemiBold (600) | `1 / 4` (当前/总数) |
| **主按钮字面** | `--type-button-label` | `14sp` / `20sp` | SemiBold (600) | `下载原图` (4字) |
| **副标题与提示** | `--type-subtitle-meta` | `13sp` / `18sp` | Regular (400) | `点击查看画师主页` (≤15字) |
