问题

白色画作与中灰背板之间是硬切边，既没有承托也没有过渡，看起来像一块板子贴在墙上。

问题

10dp 圆角与右栏 16dp 卡片不是一套圆角语言，同屏出现两种观感。

方案 · 承托画框

提议 暗内衬卡面 + 同心圆角 + 高光描边 + 落影；环境光可选、默认关

01画框承托

画作外裹一层内衬（默认 10dp），内衬比背板暗一档（黑 16%），跟右栏卡片同一套 "卡面落在背景之下"的语言；再压 1px 白色 10% 高光边定轮廓。

02同心圆角

画作 16dp，外框 = 16 + 内衬 = 26dp，同心不打架；跟右栏卡片同一套圆角体系。

03落影

向下 30dp、扩散 100dp、黑 38%。实现上不用 Modifier.shadow （本仓实测出灰边），走自绘渐变。

04环境光（可选）

画作四周一圈同图柔光，只在画布范围内衰减到透明。默认关；调上去可以压一点左右色温的割裂感， 代价是白画周围的边界会变软。
