前提：遵守 一次烘焙 / 单一表面 / 空闲零帧 三条渲染契约
验证：用户截图 + 任务管理器复测
结论一

糊图不是问题，实时糊才是。背板改成进页烘一次的静态位图，每帧只剩一次贴图。

结论二

割裂线来自两块实底相接。全窗只留一张背板，顶栏、侧栏槽、内容一律不画实底，线就没有生成条件。

结论三

静置的 6.5% / 8.1% 由常驻无限动画 × 每帧重糊相乘而成。动画按状态创建，空闲时帧钟停摆。

旧结构里两条虚线就是现在截图上的割裂线：24dp 内容槽内边距 + 46dp 顶栏下沿。

三条渲染契约

UI 怎么做都行，但这三条必须在实现里写死。它们分别对应：糊图不再每帧重算、割裂线失去生成条件、静置帧钟停摆。

C1 · BAKE ONCE

背板烘一次

进页时解码 1/8 缩略图 → Skia 一次 makeBlur(σ≈12) → 存成 ImageBitmap。绘制只做一次 drawImage，scale/alpha 交给 graphicsLayer。

缓存键：url + 窗口尺寸档 + 主题。换图、跨档 resize、切深浅才重烘。

为什么：现在每画一帧都在跑全窗原尺寸 80dp 高斯；烘一次把成本从"每帧"挪到"每次换图"。
C2 · ONE SURFACE

全窗只有一个面

背板铺到窗口四边；顶栏只压上沿渐变、侧轨不画面板、内容槽取消 24dp 内边距、画布不叠第二张背板。所有分组只靠 半透明实底 + 圆角 + 发丝边 表达。

为什么：割裂线 = 两块不透明底色在 padding 边上相接。没有第二块实底，就没有线。
C3 · ZERO IDLE FRAMES

空闲不建动画

任何 rememberInfiniteTransition 都必须包在 if (busy) 里；复制/下载/加载结束即销毁。加载态用静态骨架，不用 shimmer。糊图区域不参与任何每帧动画（不做缓慢缩放/呼吸/视差）。

为什么：无限动画会让帧钟一直转，哪怕没人读它的值；帧钟一转，整窗重画一遍。

背板烘焙管线

把"效果"改成"素材"：一次性完成，之后每帧只是把一张已经糊好的位图贴上去。

① 进页 / 换页拿到 backdropUrl；先铺纯底色 #2C2C34，用户不会看到空白。
→
② 低分辨率解码按窗口短边 / 8 取采样尺寸（1440 宽 ≈ 180px），IO 线程解码。
→
③ 一次高斯Skia ImageFilter.makeBlur(σ=12) 烘进位图；σ 只跟采样尺寸有关。
→
④ 缓存 + 贴图按 url+尺寸档+主题 记住；之后每帧 drawImage，0 次高斯。

成本对比：现在是一帧一次全窗 80dp 高斯（1768×1286，σ≈80dp×密度）；烘一次约 30–60ms，之后每次绘制只是一张 180px 位图放大贴满 —— 可以忽略不计。不做的事：不给背板做实时 backdrop-filter、不做缓慢呼吸缩放、不做随鼠标视差。

UI 改动清单

按"现状 → 方案"逐条对应。前三条是去线的结构改动，后五条是视觉与静置体验。

位置现状方案收益
背板全窗实时 80dp 高斯，每帧重算进页烘一张低分辨率位图，按 URL+尺寸+主题缓存每帧成本从高斯降为一次贴图
顶栏46dp 实底；或自绘一份背板副本，与内容取景对不齐不再画实底，只压上沿 42% → 0 的渐变，保面包屑可读y=46 的横线消失；顶栏和内容同一张图
内容槽壳给 24dp 左右内边距，槽外是另一块实底取消内容槽内边距；内边距由各内容块自己带，背板直达左右边缘x=24 的竖线消失；窗口观感变宽
侧栏264/76dp 面板，右缘有底色分界详情页收成 64dp 图标轨：无底色、无分隔线，图标直接浮在背板上少一条竖向边界，画布多出 200px
右栏一整块实底 + 浅色卡片，卡片和面板两层灰只留浮卡：16dp 圆角、1px 发丝边、投影，卡间露背板；半透明实底（alpha .58）层次清楚，边是"看得出的边"
大图Fit 居中，四周大块空背板保持 Fit；加 12dp 圆角 + 1px 高光描边 + 外投影，四周留白读作空气图有"摆上去"的实体感，不糊在背景里
动作条复制图标常驻无限旋转常驻但静止；只有进行中才转，结束即停；收藏/下载态用颜色与对勾去掉常驻动画，静置帧钟停摆
加载态转圈 + shimmer 骨架静态骨架块（无动画）；超时给"重试"，不无限转慢网也不烧帧
补齐入口只有两枚无名箭头；没有作品简介；评论只有一个"展开"两侧常显「上一张 / 下一张」标签钮；简介进作品头卡（两行 + 展开）；评论卡带输入框与「发送」详情页该有的信息与动作都留在原地

验收标准

静置 30s：任务管理器 GPU < 1%，CPU < 1%（当前 8.1% / 6.5%）
无线：窗左沿、顶栏下沿、右栏左缘截图逐像素无台阶
换图：新背板 ≤ 120ms 上屏，期间只有纯底色，不闪黑
resize：1440 / 1920 / 2560 三档来回拖，背板不拉伸变形、不出现缝
动画：暂停后 1s 内画面完全静止；无任何元素继续动
两档皮肤：深/浅各出一张截图对照
