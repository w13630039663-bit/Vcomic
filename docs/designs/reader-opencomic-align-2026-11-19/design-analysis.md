# 阅读器对齐重做 — 页面结构分析（目标：主人提供的 OpenComic 截图三张）

## 0. 范围

重做两件 UI：阅读器顶栏（DesktopReaderTopBar）、阅读器设置弹窗（ReaderSettingsOverlay → 四段 tab）。
同时翻页机制按下方机制规格对齐（见 component-spec.md 第 8 节）。
视觉目标 = 主人 2026-11-19 提供的三张 OpenComic 实物截图；本文尺寸为截图实测估算值（已标注）。

## 1. 设置弹窗整体结构（截图 1 / 2）

- 弹窗：深色玻璃底（延续现 ReaderSettingsOverlay 外壳 300dp 宽；本次加宽到 ≈600dp，四 tab 内容才放得下），圆角 16dp，1dp 发丝描边，最大高 ≈80% 窗高，内部独立滚动。
- 顶部 tab 条：4 个分段 tab 横排（电子书 / 页 / 筛选 / AI），选中段高亮胶囊（淡蓝底深字），未选中描边胶囊。tab 高 ≈40px（估算），圆角 999。
- 内容区：单列纵向滚动；条目行 = 左文案 + 右控件（开关 / 数值）；行高 ≈52px（估算）；分组之间 1px 分隔线 + 上下 12px 留白（估算）。
- 控件形态：
  - 模式选择 = 2 列卡片网格（截图 1 顶部 6 张卡），卡片 = 图标 + 文案 +（可选）⚙ 圆钮；选中卡 = 淡蓝底。
  - 开关 = M3 胶囊 Switch（现有件复用）。
  - ⚙ 圆钮 = 行尾齿轮图标钮，点开对应参数弹窗。
  - 下拉 = filled 灰底圆角 8dp 全宽条（截图 2「模型」样式）：上行 11sp 灰标签 + 下行正文值 + 尾部 ▾。
  - 滑条 = 全宽 Slider + 右上角灰数值（16px / 3.0% / 2.0mpx 样式）。
  - chip 组（旋转三连）= 描边胶囊横排，图标+文案。

## 3. 「筛选」tab 清单（对齐原版 filters + 保留现有快捷预设）

1. 滤镜预设行（现有 5 颗预设 chips 保留，置顶）
2. 亮度 — 滑条 0–400%，默认 100%
3. 饱和度 — 滑条 0–400%，默认 100%
4. 对比度 — 滑条 0–400%，默认 100%
5. 色温（暖褐）— 滑条 0–100，默认 0（替换现「深褐复古」开关）
6. 色相旋转 — 滑条 0–360°，默认 0
7. 黑白（灰度）— 开关（替换现「黑白反色」拆成两枚）
8. 负片 — 开关（灰度+hue180 组合）

## 4. 「AI」tab 清单（截图 2 顺序）

顶部：提取文档图像（PDF 和 EPUB）— 开关（与页 tab 同键）。
三张功能区卡片，每张 = 上下两格对比小图（before / after）+ 标题行 + 控件：

1. **AI 痕迹去除**：开关 + 模型下拉（快速 v2 / 均衡 v3(默认) / 质量 v3）+「保持色调平缓」开关 + 痕迹尺寸滑条 1–10%（默认 3.0%）
2. **AI 去网纹**：开关 + 模型下拉（快速 v4 / 硬核快速 v4(默认)）+「保持大网点」开关 + 尺寸滑条 1–10%（默认 3.0%）
3. **AI 增强**：开关 + 模型下拉（快速 v3 / 质量 v3）+ 最大输入分辨率滑条 0.2–50 Mpx（默认 2.0）+「自动比例」开关 + 比例下拉（2x / 4x，默认 4x）

对比小图：当前页中央取 240×120 区域，开关态实时渲染两格（before=原图，after=过处理），点卡片任意处刷新。

## 5. 「电子书」tab

- 仓内无 PDF/EPUB 加载路径（探查确认：阅读器页源仅图片/压缩包）。
- 该 tab 放空态文案卡：「暂无电子书内容」副句「支持 PDF / EPUB 后解锁提取」。不放假开关。

## 6. 顶栏结构（截图 3 对齐）

常驻玻璃条（现有 chrome 显隐机制不变），高 44dp（现值保留），图标钮 32dp 圆形 hover，分组竖分隔线 1dp：

- 左组：返回 ‹（保留）｜上一章 ｜下一章 ｜（保留现有真功能）
- 中组 1：深色切换（画布背景循环：深→浅→绿）、首页、上一页、下一页、末页
- 中组 2：书签（toggle）、书签列表（开目录浮层书签 tab）
- 中组 3：适应屏幕（循环适配档）、1:1（缩放复位 100%）、缩小、放大
- 中组 4：放大镜（现有浮层）、跳页（现跳页对话框）
- 右组：电子书（设置弹窗·电子书 tab）、页（·页 tab）、筛选（·筛选 tab）、AI（·AI tab）、更多（⋮ 菜单：倒序开关、自动翻页档、显示页码、隐藏顶栏）
- 页码文本移入「更多」菜单旁固定显示（现有保留，位置贴右组前）。

图标语义沿用原版 Material 图标名（first_page / navigate_before / navigate_next / last_page / bookmark / collections_bookmark / fit_screen / 1:1 文本 / zoom_out / zoom_in / search / auto_stories / menu_book / invert_colors / auto_awesome / sort / more_vert）。

## 7. 响应式

- 窗宽 <1400dp：右组「电子书/页/筛选/AI」收成单颗「设置」钮（开弹窗默认页 tab）；中组 4 折叠进更多菜单。
- 弹窗高不足：内容区滚动（现有 Modifier.verticalScroll 模式）。
