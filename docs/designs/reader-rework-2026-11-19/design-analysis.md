# 阅读器 UI 重做 — 现状分析

## 1. 边界

### 必须保留
- 画布优先的阅读体验：图占满，控件不抢视线
- 现有功能面：翻页、章节切换、书签、缩略条、目录、跳页、阅读设置、放大镜、旋转、滤镜
- 品牌视觉体系：沿用 `sidebar-macos-rework-2026-11-19` 的 accent / ink / 玻璃底令牌
- 深浅双模式

### 可以重构
- 浮层数量与层级关系
- 浮层定位方式（禁止手写魔法数让位）
- 状态组织（六个布尔 → 一个密封类型）
- 尺寸、圆角、动效全部令牌化
- 常驻策略（本次核心议题）

### 不动
- 阅读器业务逻辑（数据源、进度入库、下载联动）
- 图文渲染管线（缩放/分块另案处理）

## 2. 最大的平庸来源

**浮层是七个各自为政的孤岛。** 每个浮层自己写位置、自己管显隐、自己写圆角，开一个要手动关掉另外两个。结果不是"不够好看"，是"没有系统"。

## 3. 现状证据

| 问题 | 位置 |
|---|---|
| 7 个浮层 | `DesktopReaderHud.kt`：TopHud(92) / BottomHud(234) / ThumbnailStrip(375) / Toc(451) / Settings(561) / JumpDialog(758) / Magnifier(821) |
| 位置魔法数 | `DesktopReaderHud.kt:589` `padding(top=70.dp, end=20.dp, bottom=84.dp)` |
| 互斥手写 | `DesktopReaderScreen.kt:907` 起 `if (visible) { 另两个 = false }` 重复多轮 |
| 尺寸裸值 | HUD 内 `8.dp`×18、`16.dp`×13、`12.dp`×9，未走 `VeneraSpacing` |
| 圆角不成体系 | 外卡 12 / 16 混用，内件 8 / 10 混用 |
| 动效无统一时长 | TopHud 上下滑、Settings 左右滑，均为默认时长 |

## 4. 重做强度

**Layout Restructure**。保留功能与内容，重排层级与组件结构；视觉语言在既有令牌内统一，不引入新风格。

## 5. 方向

> 做一个以画布为唯一主语的桌面漫画阅读器界面，用克制的深色玻璃浮层语言，核心突破是"常驻面积可调"的三层结构。

## 6. 常驻策略（已定）

主人选定 **E 左侧缩略条**（参考桌面漫画阅读器形态）：

- 左侧 `120.dp` 常驻缩略条 + 底部页码/进度
- 顶部 `40.dp` 通栏工具栏（返回、标题、章节、缩放组、适配、书签、页码、目录、设置）
- 画布让出宽度，不叠加遮图
- 其余方案保留在稿内可切换，供后续对比

备选（稿内仍在）：

- A 零常驻：全干净，移动鼠标才出现
- B 常驻进度条：底部一条极细进度与页码
- C 常驻竖向工具轨：右侧一列图标
- D 常驻顶栏：顶部一条标题与章节
