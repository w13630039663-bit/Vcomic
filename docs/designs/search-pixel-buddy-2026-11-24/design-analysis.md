# 搜索与画廊像素伙伴（分列踩台阶 × 列光流）· 视觉与交互解构

- 前置归档：`desktop/docs/designs/sidebar-pixel-buddy-2026-11-24/`
- 归档日期：2026-11-25

## 1. 承载区域与双页布局适配
- **漫画搜索页（`DesktopSearchScreen`）**：支持单列横卡、双列横卡、多列网格（4~6 列）；搜索时 `DesktopSearchField` 从 `56%` 展宽至 `100%` 全宽，宠物在输入框顶部巡逻陪等。
- **画廊搜索页（`DesktopGallerySearchScreen`）**：支持 Booru / Pixiv 多列错落瀑布流（`LazyVerticalStaggeredGrid`）及列表/珍藏册轴；搜索时同步上报 `searching` 状态给像素伙伴总线，输入框保持展开陪等。
- **顶层透明覆盖层（`PixelBuddyOverlay`）**：覆盖于主内容区最顶层，仅消费宠物与便便命中热区指针事件，绝不阻挡卡片点击与列表滚动。

## 2. 分列踩台阶 + 全列光流交互链路
1. **自动按列聚类**：搜索加载完成且首屏卡片就位（短防抖稳定收集可见矩形）后，按卡片中心横坐标自适应聚类分列，列内按顶部坐标从上到下排序。
2. **首屏高点台阶种子**：每列选取顶部首屏高点前 1~2 张作为“台阶种子”，由在场全部宠物（支持 1 / 2 / 3 只任意数量）按区域偏好 + 距离代价动态认领，绝不闲置、不抢单、不横穿下方图片。
3. **抛物线跃迁（`leap`）+ 顶边实时擦亮（`skim`）**：宠物以真实毫秒计时的抛物线跃上目标卡片左上角，再贴着卡片顶边小跑向右滑过；卡片暗幕蒙版随宠物横坐标同步向右擦除，露出封面与文本。
4. **全列多米诺光流（`lightBeams`）**：某列最后一张种子卡擦亮后，沿该列中心向下放出垂直像素微光流，顺次穿过下方剩余全部卡片并依次触发唤醒扫光与小火花。
5. **收尾与滚动即时闪避**：全部种子完成后宠物冒星并抛物线跳回侧边栏；用户一旦在描绘期间滚动页面，宠物立即中断当前台阶任务跳回侧栏，未唤醒卡片就地快速展开。
