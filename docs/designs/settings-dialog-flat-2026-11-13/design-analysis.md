# 设置弹窗扁平化 · 设计稿逆向分析

> 依据：主人提供的一张桌面软件设置窗截图（1440×1000 视口）。截图为唯一视觉依据；
> 本文只描述可观察到的形状与量得的数值，不引用截图所属软件的名称、文案或功能。
> 标注「确定」= 可由截图直接量出或数出；「估算」= 按比例换算或目视比对得出，落地时允许微调。

## 1. 页面完整结构

整窗为**居中模态弹窗**，压在约 50% 黑色遮罩上；遮罩之外是主界面，不做任何改动。

弹窗内部按三带解耦：

| 带 | 位置 | 内容 | 是否独立滚动 |
|---|---|---|---|
| 顶栏 | 弹窗顶部，横跨整宽 | 三槽：左搜索 / 中标题 / 右关闭 | 否 |
| 左轨 | 顶栏以下，左侧固定宽 | 用户卡、分区导航、版本尾注 | 分区列表独立滚动 |
| 右栏 | 顶栏以下，剩余宽 | 分组标题 + 扁平行 | 独立滚动 |

顶栏**不随分区切换改变结构**：切换分区只换中间标题文字与右栏内容，左轨选中态同步。

### 区域尺寸与比例

| 参数 | 值 | 依据 |
|---|---|---|
| 弹窗宽 | 约 760dp | 估算：截图弹窗约 760px，视口 1440px |
| 弹窗高 | 约 790dp | 估算：截图弹窗约 790px，视口 1000px |
| 弹窗圆角 | 24dp | 估算：截图圆角约 24px |
| 顶栏高 | 56dp | 估算 |
| 左轨宽 | 200dp | 估算 |
| 右栏内容左右留白 | 24dp | 估算 |
| 弹窗外遮罩 | 黑色约 50% | 估算 |

几何约束（同心圆法则 `Outer = Inner + Padding`）：
弹窗圆角 24 = 内容容器内圆角 16 + 内容到弹窗边 8（左轨/右栏贴弹窗内缘时以 8dp 收口）。
行内彩色图标块 24dp、圆角 7dp；外层行点击区高 48dp、圆角 8dp，行左右内距 12dp → 图标块外缘到行外缘 12dp。

### 视觉层次

- 只有**一层**表面：弹窗底色为中性深灰，左轨与右栏**没有独立卡面**，靠 1dp 竖向分隔线分区。
- 右栏无卡片、无阴影、无毛玻璃；分组之间靠留白与 1dp 行分隔线建立节奏。
- 彩色只出现在：分区图标块、行图标块、开关选中态。文字与分隔线一律中性灰。
- 层级顺序（由强到弱）：弹窗底 → 选中行浅色条 → 分组标题 → 行标题 → 当前值 / 说明 → 分隔线。

### 分组与行文案（本仓真实数据，非截图文案）

分组由 `DesktopSettingsCard.title` 提供，行由 `DesktopSettingRow` 六类提供。
截图里属于第三方软件的账号、订阅、模型等条目**一律不移植**；本仓按「无落点不摆假把手」口径只摆真实存在的 11 分区与真实设置行。

## 3. 视觉语言边界

- 禁：卡片网格、玻璃/毛玻璃、渐变主按钮、大圆角胶囊、emoji、拟人化与比喻文案。
- 禁：主标题超过 6 字、副标题超过 15 字（AGENTS.md 明令）。分区名沿用现有 11 个真实名称，
  均满足该约束；新文案一律键盘/桌面标准术语。
- 图标：一套线性图标，1.6–1.8px 描边，`currentColor`，尺寸一致，光学对齐文字；彩色图标块为纯色不渐变。
- 无障碍：所有可点元素有可见焦点环；Tab 顺序 = 视觉顺序；文字对比 ≥4.5:1；点击区 ≥44dp；
  关闭按钮有内容描述；图标按钮不单独承载语义（旁有文字或内容描述）。

## 4. 响应式视口规则

弹窗尺寸用 `sizeIn` 约束而非固定像素：

| 视口 | 弹窗行为 |
|---|---|
| ≥1100×900 | 目标 760×790dp，居中 |
| 720–1100 宽 | 宽度随可用宽收缩，最小 720dp；左轨 200dp 固定，右栏吃剩余 |
| <900 高 | 高度随可用高收缩，最小 480dp；左轨与右栏各自独立滚动 |
| <720 宽 | 左轨收至 64dp 只留图标 + 选中态；右栏仍可滚（本仓桌面端最小窗兜底） |

不做手机布局：本仓是桌面端，弹窗是窗口内模态。

## 5. 与现状的差距（决定改动面）

| 现状 | 目标 | 改动部位 |
|---|---|---|
| 右栏卡片网格（卡头 + 卡壳 + 行） | 分组小标题 + 扁平行，无卡面 | 渲染层新增 |
| 顶栏在右栏内（左轨顶上是搜索框） | 顶栏横跨整窗，搜索移入顶栏左槽 | 渲染层新增 |
| 页头有 uppercase 副标题与「N 项」徽标 | 删除，只留居中标题 | 渲染层 |
| 左轨 280dp、34dp 行、材料图标单色 | 200dp、40dp 行、彩色圆角图标块 | 渲染层新增 |
| 弹窗 720–920×480–640，16dp 圆角 | 760×790、24dp 圆角 | 装配分支 |
| `SettingsPageTemplate` 由源管理详情共用 | 不动，避免连坐 | 不改 |

数据与逻辑层（`DesktopSettingsSection` / `DesktopSettingRow` / `DesktopSettingsCard` / 全部读写口 /
搜索过滤 / 两个凭据对话框）零改动。
