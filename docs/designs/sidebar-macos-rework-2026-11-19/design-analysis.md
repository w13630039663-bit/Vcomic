# Venera 侧栏 macOS 激进重做 — 视觉解构与页面分析

## 1. 页面结构与区域划分（自上而下）

1. **贴边容器（Sidebar Shell）**
   - 展开态宽度：`248.dp`（贴左边缘，无外边距，右侧 `1.dp` 极细高光分割线）。
   - 折叠态宽度：`60.dp`（窄轨图标模式，保留品牌 Logo、主导航图标、桌宠迷你态、头像与展开按钮）。
   - 材质：macOS Sequoia/Tahoe 深度毛玻璃（半透明深色底 `rgba(22, 23, 28, 0.74)` + 顶部 `1.dp` 微弱内高光 + 右侧 `1.dp` 边框）。

2. **顶部品牌区（Brand Header）**
   - 保留现有 `[V] VENERA` 样式：`26.dp` 圆角渐变 Logo + `VENERA` 标题。

3. **主导航区（Primary Nav）**
   - 4 项核心入口：首页、漫画搜索、画廊、收藏（右侧可带数量弱提示）。
   - 行高 `30.dp`，圆角 `7.dp`，选中态为干净的半透明磨砂高亮 `rgba(255,255,255,0.11)` + 左侧 `3.dp` 强调色竖条。

4. **中间可折叠分组区（Scrollable Finder Groups）**
   - 搜图并入「画廊」分组第一项，消除孤立入口。
   - 三大可折叠分组顺序：**画廊**（搜图、每日热门、收藏与历史、关注画师、我的 pixiv）→ **漫画**（阅读历史、阅读统计）→ **工具**（源管理、备份与还原）。
   - 分组标题行高 `24.dp`，带可旋转小箭头（`▾` / `▸`），点击平滑折叠/展开子项。
   - 子项行高压缩至 `28.dp`，右侧显示数量/状态弱提示（如 `HOT`、数字）。

5. **桌宠区（Pet Zone）**
   - 保留在列表下方、底栏上方。
   - 磨砂气泡带底部小尖角，桌宠脚下带极淡紫色环境光斑与轻柔呼吸浮动。

6. **极简单行底栏（Footer Bar）**
   - 固定高度 `46.dp`，顶边带 `1.5.dp` 下载进度光带（有活跃下载时显示）。
   - 左侧：圆形头像（带在线绿点）+ 用户名（点击触发账号弹窗/页面）。
   - 右侧并排 3 个 `28.dp` 图标按钮：下载与本地（带环形进度与角标）、设置、折叠/展开侧栏。
