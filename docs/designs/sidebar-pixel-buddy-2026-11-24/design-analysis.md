# 侧栏像素互动伙伴 · 视觉与交互解构（Design Analysis）

- 对应方案稿：`desktop/docs/designs/sidebar-pixel-buddy-2026-11-24.html`
- 归档日期：2026-11-24

## 1. 页面结构与承载层级
- **顶层覆盖画布（PixelBuddyOverlay）**：位于主窗体最上层透明 `Box`，不拦截空白区域鼠标事件，仅在命中宠物或像素便便热区时消费指针事件。
- **活动轨道体系**：
  1. **侧栏右边界（`side`）**：紧贴 `VeneraSideBar` 右侧分割线，宠物顺时针旋转 90°，四足踩在竖直边沿上上下爬行。
  2. **顶栏底边（`top`）**：爬至侧栏顶端拐角自动转弯 90° 上顶栏，旋转 180° 倒挂爬行；回到左端拐角自动转回侧栏。
  3. **搜索框右上角（`search`）**：聚焦漫画/画廊搜索框时，宠物抛物线跃上框沿，跟随搜索框从 56% 收窄态平滑展宽至 100% 全宽；打字时轮流蹦跶并实时在框上方用像素块拼字；回车确认后整框扫光并自动收窄。
  4. **漫画/画廊卡片顶边（`card`）**：通过轻量表面注册表收集可见卡片顶边，宠物可主动跨卡跳跃、被甩出后落脚弹跳，或在搜索完成后化身施工队带像素砖块拼合卡片。
  5. **沉浸避让**：进入阅读器或全屏看图器时自动隐藏退场，不遮挡内容。

## 2. 视觉语言（极简方块像素）
- 对齐纯方块无描边语法：逻辑像素格 `3.dp`，离散动画节拍 `100ms`，零黑描边、零杂色噪点、标志性 `1×2` 黑色竖瞳与四条细腿。
- 预设 3 套低饱和纯色皮肤：薰衣草紫猫（`#947FD6`）、暖橘小方块（`#D97757`）、雾蓝小兔（`#6B9FD4`）。
