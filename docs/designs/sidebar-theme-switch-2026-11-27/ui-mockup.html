跨平台位置获取（零弹窗）

Windows / Linux 均无需系统 GPS 权限：优先 IP 粗定位获取经纬度，再调免 Key 的 Open-Meteo 气象接口；支持设置手动指定城市，彻底解决开代理 IP 漂移问题。

5 种天气 × 昼夜视觉层

晴天（日晕/星芒流星）、多云（厚云半遮日/月）、雨天（斜雨丝+底边水花涟漪）、雷暴（紫黑乌云+随机分叉电光闪耀）、飘雪（景深雪花+底部薄雪积线）。

低功耗与隐私兜底

启动拉取并缓存 30 分钟，断网或关闭天气联动时无感退回原版晴空/星夜；悬停与切换时全速播放粒子，窗口失焦或闲置可节流降帧保护 GPU。
