# 站点墙 · 逆向分析

规格名:`site-sources-rework-2026-11-20` · 依据:`ui-mockup.html`(同目录)· 日期:2026-11-20

## 1. 页面结构

单列滚动页,左缘沿用 66dp 玻璃轨,主内容区自上而下四段:

| 段 | 内容 | 高度口径 |
|---|---|---|
| 页头 | 标题「站点」+ 计数 + 搜索 + 三档 + 「添加站点」 | 内容高,下距 20 |
| 大卡行 | 已开启的前 3 站,每张跨两行 | 卡高 206,3 等分 |
| 普通卡行 | 其余已开启站 + 末尾添加卡 | 卡高 96,3 等分 |
| 索引带 | 未启用站点,4 列细条 | 条高 44,4 等分 |

## 2. 区域尺寸与比例

- 内容区左右内距 28;网格列间距 14、行间距 14。
- 卡宽 = (内容宽 − 2×14) / 3;稿按 1340 窗宽取样约 404。
- 大卡 = 2 行 + 中间距 = 206;与两张普通卡视觉等高。
- 抽屉宽 424,占窗宽约 1/3;抽屉内左右内距 20。

## 3. 视觉层次

| 层 | 底 | 描边 | 用途 |
|---|---|---|---|
| 页面 | `app-bg` | 无 | 舞台 |
| 大卡 | 白 8.5% → 2.2% 竖向渐变 | 白 7% | 三颗常用站,视觉最重 |
| 普通卡 | 白 6.2% → 3% 渐变 | 白 7% | 其余开启站 |
| 添加卡 | 透明 | 白 14% 虚线 | 补位 + 第二入口 |
| 索引条 | 透明 | 白 9% 虚线 | 未启用 26 个,极轻 |
| 抽屉 | 比页面亮一档 `#1b1e24` | 左缘 1px + 左向投影 | 管理面 |
| 遮罩 | 黑 52% | — | 抽屉背后 |

不用站点品牌色染底;彩色只来自图标本体。

## 4. 逐元素参数

- 图标槽:34×34,圆角 10,内图 26×26 `contain`;大卡 52×52、内图 38。
- 站名:普通卡 16/650,大卡 27/650,行高 1.1~1.3,单行省略。
- 副行:11,含状态徽章(绿胶囊 10)与「· N 项配置」。
- 页头标题:24/700;计数 11.5 三级字。
- 搜索框 172×32;三档 24 高;主按钮 32 高、圆角 9。

## 5. 状态

- 已开启 / 未启用(索引带)/ 未登录 / 已登录 / 已修改 / 抽屉开。
- 空态:搜索无结果 → 卡区一句提示;全部未启用 → 卡区空,索引带在。
- 停用最后一颗(数据闸门):卡片开关置灰且念原因,与旧屏同一条纪律。

## 6. 响应式

- ≥1180:3 列卡 + 4 列索引条。
- 820~1180:卡改 2 列,索引条 3 列。
- <820:卡 1 列,索引条 2 列;抽屉改满宽。

## 7. 与旧屏的关系

旧屏是「左清单 280 + 右详情面板」的主从形;新屏取消左清单与右常驻面板,原右栏三段(账号/站点设置/脚本)整体搬进抽屉,交互入口一个不少。
