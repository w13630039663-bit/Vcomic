## 1. 结论

**站点墙**:这一屏的形状从「左清单 + 右开关面板」改成**卡片墙**,页面主行为从"配置站点"变成"去某个站看内容";账号 / 站点设置 / 脚本三段管理挪进卡片上的「⋯」抽屉,平时不出现在页面上。

分三层落地:

| 层 | 目标 |
|---|---|
| 视觉 | 已开启 = 实底卡(名字 + 状态 + 浏览),已关闭 = 虚线幽灵卡;顶部一栏:标题、计数、搜索、「全部 / 已开启 / 未启用」、「添加站点」 |
| 交互 | 点卡片 = 进入该站浏览;「⋯」= 抽屉(账号/设置/脚本);幽灵卡「启用」= 一键开启;「添加站点」= 在线站点 / 导入脚本 / 检查更新 |
| 数据 | 启停、登录、站点设置、脚本编辑、撤销改写、导入与更新全部保留;只新增"卡片副信息"(设置项数)与"进入站点"的导航接线 |

## 3. 方案明细

### 3.1 视觉层

- **页面**:顶部一行 = 标题「站点」(24/700) + 计数(11.5 三级字) + 右侧工具(搜索 172×32、三档分段、主按钮「添加站点」)。左缘沿用 66dp 玻璃轨。
- **网格**:12 列 × 行高 96、间距 14。已开启的**前 3 站是大卡**(跨 4 列 × 2 行,图标 52、站名 27,海报式竖向排布);其余开启站为普通卡(4 列 × 1 行);末尾一枚虚线「添加站点」卡补满行,不与顶部按钮重复入口语义(顶部是常驻,卡片是补位)。
- **未启用**:不进卡片网格,收成**4 列细索引带**(高 44,虚线边,左站名右「启用」),26 个一屏可览;点击就地启用。
- **已开启卡**:`surface` 微渐变底 + 1px `白 7%` 边;名字 16/650,副行 11(内置站点 · N 项设置,登录态用绿胶囊徽章);底部左「浏览 →」11.5 三级字,hover 转 accent;右上「⋯」常态 45% 透明,hover 全显。
- **幽灵卡(已关闭)**:透明底 + 1px 虚线,名字与副行降到三级字,底部左「启用 →」;整组排在「未启用 N 个」分隔线之后。
- **抽屉**:宽 424,右侧滑入,底色比窗口亮一档(`#1b1e24` / 浅色 `#fff`),左侧 1px 描边 + 向左投影;背后遮罩 52% 黑。抽屉内四块:启用开关行、账号、站点设置、脚本。
- **色彩**:accent 只用全站唯一蓝(深 `#0A84FF` / 浅 `#0A63F6`),绿只用于「已登录」徽章,不引新色、不做站点品牌色。

### 3.2 交互层

| 能力 | 做法 | 效果 |
|---|---|---|
| 进入站点 | 点已开启卡任意处 | 跳到该站浏览视图(探索页预选该源) |
| 管理某站 | 卡右上「⋯」 | 右侧抽屉,承载账号 / 设置 / 脚本 |
| 启用幽灵卡 | 「启用 →」 | 就地变实卡,不跳屏 |
| 停用 | 抽屉顶部开关 | 卡降为幽灵卡 |
| 添加站点 | 顶部主按钮下拉 | 在线站点 / 导入站点脚本 / 检查更新 |
| 筛选 | 三档分段 | 全部 / 已开启 / 未启用;搜索按站名 |
| 空态 | 搜索无结果 | 卡区内一句提示 |

### 3.3 数据层

- 启停、登录、站点设置读写、callback、编辑脚本、撤销改写、导入、检查更新:**全部沿用现有回调**,抽屉只是换容器。
- 卡片副信息「N 项设置」来自既有 `DesktopSourceSettings` 解析结果,不新增读数。
- 显示名兜底:站名为空依次退「内置站点 → key」,不让卡空着。
- 「进入站点」需要一次导航接线:复用探索页既有源选择(`exploreSourceKey`),不新建路由。
- 偏好键、`DesktopSourceStore` 写盘逻辑不变。

### 3.4 图标策略(2026-11-20 实测)

34 个随包源逐个探过:`favicon.ico` / `apple-touch-icon.png` / `favicon.png` 三条常见路径先拿 17 个;再按首页 `link[rel=icon]`、`site.webmanifest` 声明的 icons、备用域名深挖一轮,补到 **24 个**;最后主人补了 CCC追漫台 与 manhuaren 的站方横版字标,各裁出图形块,合计 **26 个**,剩 8 个。

- **脚本里没有图标字段**:34 个 `.js` 全搜过,`icon` / `iconUrl` / `favicon` 均无,只能外抓。
- **24 个有真图标**:其中 180×180 的(comic_walker、hitomi、Komga)最清晰,48×48 的(GoDa、Komiic、漫蛙、热辣漫画)够用,其余 32×32 或 16×16。
- **8 个没有**:happy、爱看漫(ikmmh)、jcomic、Kavita、manhuagui、mh1234、mycomic、picacg。原因是反爬返网页(jcomic)、连不上(happy、manhuagui、mh1234)、空文件(mycomic 0B)、404/403(picacg、ikmmh)、自建服务(Kavita)。
- **横版字标的处理**:CCC追漫台(300×86)与 manhuaren(166×39)站方只给横版字标,已各裁出左侧图形块(`assets/icons/ccc.png` 112×86、`manhuaren.png` 62×62);方形槽内 `contain` 居中显示。落码时同一裁切参数写进抓取脚本。
- **做法**:真图标优先,拿不到的用**站名首字块**(英文取两字母,如 Ka/Ko/La),两者同一个 34dp 圆角槽位;框内不用站点品牌色,守 accent 唯一装饰色。
- **资产落地**:构建期一次性抓取,产物放 `desktop/src/main/resources/sources/icons/<key>.<ext>` 随包分发(离线可用、无运行时网络请求);抓取脚本扩 `desktop/scripts/build_source_icons.mjs`,**失败站点名单与已试路径写进脚本头注**,避免下次重试。
- **自建服务三颗**:Kavita / Komga / Lanraragi 抓到的是官方 demo 站图标,不代表用户自己的实例 —— **定为首字块**,不做官方图标。
- **已知待修**:少年Jump+ 的 ico 有 10 帧、256×256 首帧透明,需按帧提取最大非空帧。
- **版权**:均为站方商标,仅用于标明"内容来自哪一站",与 2026-09-30 图库两站同一口径。

实测原始账:`assets/icon-probe.tsv`;图标文件:`assets/icons/`。
