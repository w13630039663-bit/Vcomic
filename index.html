Android 主线 · Kotlin + Jetpack Compose

手机端也在：venera-miuix

Kotlin + Jetpack Compose 写的 Android 主线，支持 Android 11 及以上。和桌面端共用数据层与 JS 漫画源协议，进度各自存在本机。

  • Miuix + Material 3 双风格切换

    Miuix 那套底栏与色板，也能切回 Material 3，用壁纸动态取色。

  • 画廊与 Pixiv 原生生态

    支持 yande.re、Gelbooru、Safebooru 与 Pixiv 榜单、画师主页、SauceNAO 搜图；水彩效果是 Beta，默认关闭。

  • 同一套 JS 源脚本生态

    兼容 ComicSource 插件协议，可以导入外部源脚本。

技术说明

Kotlin + Compose，不是网页套壳

桌面端用 Kotlin 和 Compose Multiplatform 编写，没有 Electron，也没有 Flutter。

34 个
内置漫画源

随包附带 34 个 JavaScript 漫画源，兼容 ComicSource 插件协议；可以逐个启停、改脚本、填账号。

Kotlin
Compose Multiplatform

不是网页套壳。滚动和切页会保留状态，从详情返回列表不会跳回顶部。

两套
收藏分开存

Pixiv 云端书签走官方接口；本地漫画和图库收藏各存一套，可以整包备份与还原。

FAQ

常见问题

内置 34 个漫画源脚本，默认启用包子漫画、拷贝漫画、禁漫天堂和 MangaDex 四个，其余在「站点」里可以随时打开。图库支持 Pixiv，以及 yande.re、Gelbooru、Safebooru 等站点。

装好就能直接用的是包子漫画、拷贝漫画、禁漫天堂和 MangaDex。其余源在「站点」页面一个个打开就行；需要登录的源，顺手把账号和 Cookie 填上，搜索时才会出结果。

每张图写入前都会检查是不是有效图片，站点返回的错误页面不会存进磁盘。到「本机已下载」里点「补齐」，只重新下载缺的页，已经下好的不会动。

在图库作品或画师主页上，画师名可以直接跳到他在 Pixiv 的主页。想找原图，可以拿一张图发起 SauceNAO 或 ascii2d 反搜，命中本站图库的条目能直接打开大图页。

可以。完整下载的章节直接从本地磁盘读取，不需要联网；只下了一部分的章节会先读本地，缺的页再联网补。

方向键 ← / → 翻页，PageUp / PageDown 翻章，Home / End 跳到开头和结尾，空格也能翻页。支持双页对开和条漫连续两种阅读方式，切换后仍会记住进度。

视频交给本机 VLC 解码，需要装 VLC，不装只影响视频播放。Ugoira 动图是应用内直接播的，不需要额外装东西。

这些站走 Cloudflare 验证，应用会用系统自带的 WebView2 开一个窗口，点过验证就好。一直过不去多半是网络或代理问题，可以在设置里配 HTTP / SOCKS5 代理。另外 Gelbooru 这类站需要填账号，没登录会返回空结果。

都在 %LOCALAPPDATA%\venera\ 下：数据库在 db\，日志在 logs\。程序和你的数据分开放，覆盖安装或升级只换程序，不碰这个目录。换电脑时在「备份与还原」里导出整包，新机器导入即可。

这两种是 Windows 11 的系统窗口效果，Windows 10 上会退回普通窗口背景。Windows 11 下可以在设置里切换 Mica、Acrylic 或实底材质。
